# 🌤️ SkyCast

**SkyCast** is a modern and responsive weather forecasting web application that provides real-time weather information for cities around the world. The application uses WeatherAPI to fetch live weather data and presents it through an intuitive and visually appealing user interface.

---

## 🚀 Features

* 🔍 Search weather by city name
* 🌡️ Real-time temperature updates
* ☁️ Weather condition display with icons
* 💧 Humidity information
* 🌬️ Wind speed details
* 📱 Responsive design for desktop and mobile devices
* ✨ Glassmorphism-inspired user interface
* 🎨 Animated background effects
* ⚠️ Error handling for invalid city names

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* WeatherAPI

## 🔗 API Integration

This project uses the WeatherAPI Current Weather API.

### Endpoint

```text
https://api.weatherapi.com/v1/current.json
```

### Sample Request

```text
http://api.weatherapi.com/v1/current.json?key=0b5c5d4dae47472da1282446261006&q=London&aqi=yes
```

### Data Retrieved

* City Name
* Country
* Temperature
* Weather Condition
* Weather Icon
* Humidity
* Wind Speed
